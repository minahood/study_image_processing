# 画像処理クイズサイト

画像処理の基礎知識を4択クイズで学べる、ブラウザ完結型の学習サイトです。

選択肢を選ぶと、対応する画像処理がリアルタイムでプレビューされ、正解・解説とともに処理結果の見た目を確認できます。

## クイズカテゴリ

- **トーンカーブ** — RGB チャンネル別の明暗・色調調整
- **カーネルフィルタ** — 平滑化・鮮鋭化・エッジ検出（Sobel、Laplacian など）
- **周波数フィルタリング** — ローパス・ハイパスフィルタ
- **幾何学変換** — 平行移動・拡大縮小・回転・アフィン変換
- **二値化・形態学処理** — 大津の二値化・膨張・収縮

## 技術スタック

- React + Vite + TypeScript
- Tailwind CSS
- Canvas API（画像処理はすべてブラウザ側で実装、サーバー不要）

## 開発

```bash
npm install
npm run dev
```
